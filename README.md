# @ankhorage/game

Platform-neutral config-driven game semantics and runtime primitives for Ankhorage apps.

> This repository is being bootstrapped. Release documentation is generated by Paradox from source documentation and examples.

## Scope

`@ankhorage/game` owns serializable game definitions, immutable session transitions, rules, entity pools, scheduling, lifecycle and emitted application outputs. Presentation belongs to `@ankhorage/zora-game`.

## Usage

See `examples/basic-usage/index.ts` for a small config-driven collection game.
